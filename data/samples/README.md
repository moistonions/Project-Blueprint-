# Synthetic sample data (NOT real)

Every file in this folder is **made up** to exercise the pipeline end to end.
The asset, part numbers, vendor and intervals are fictional and must not be
used as maintenance guidance. Documents loaded from here are tagged
`is_sample=true` and shown with a SAMPLE badge in the app.

- `sample_oem_spec.txt` – fictional OEM maintenance table for asset `SAMPLE-PUMP-01`
- `sample_vendor_schedule.txt` – fictional vendor schedule with a missed task,
  a stretched interval, a tighter interval and an extra task
- `sample_field_log.txt` – fictional service notes explaining the extra work

Real OEM manuals go in `data/oem_manuals/`, not here.
